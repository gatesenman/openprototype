User Journey Map

Relevant source files The following files were used as context for generating this wiki page: - [src/ai/flow.ts](https://github.com/gaosichun888/openprototype/blob/main/src/ai/flow.ts) - [src/ai/generate.ts](https://github.com/gaosichun888/openprototype/blob/main/src/ai/generate.ts) - [src/ai/localGenerator.ts](https://github.com/gaosichun888/openprototype/blob/main/src/ai/localGenerator.ts) - [src/journey/journey.ts](https://github.com/gaosichun888/openprototype/blob/main/src/journey/journey.ts) - [src/schema/types.ts](https://github.com/gaosichun888/openprototype/blob/main/src/schema/types.ts) - [src/views/JourneyView.tsx](https://github.com/gaosichun888/openprototype/blob/main/src/views/JourneyView.tsx)

The User Journey Map is a product management artifact within OpenPrototype that visualizes a persona's experience over time. It represents the "Product Management" layer of the application, bridging high-level requirements with specific design frames. The system supports manual creation, AI-assisted generation, and interactive visualization of emotion curves.

Journey Map Schema

The data structure for a journey map is defined within the GpoDocument and resides in src/schema/types.ts. It is composed of a persona, a scenario, and an ordered list of stages.

Core Types

  • JourneyMap: The root entity containing metadata, persona details, and a collection of JourneyStage objects [src/schema/types.ts:241-250](https://github.com/gaosichun888/openprototype/blob/main/src/schema/types.ts#L241-L250).
  • JourneyStage: A discrete step in the user journey. It contains arrays for qualitative data and a numeric JourneyEmotion score [src/schema/types.ts:252-262](https://github.com/gaosichun888/openprototype/blob/main/src/schema/types.ts#L252-L262).
  • JourneyEmotion: A scale from -2 (Very Frustrated) to 2 (Very Satisfied) [src/schema/types.ts:264-264](https://github.com/gaosichun888/openprototype/blob/main/src/schema/types.ts#L264-L264).
  • JourneyRow: Dimensions of the journey matrix: actions, touchpoints, thoughts, emotion, pains, and opportunities [src/journey/journey.ts:14-22](https://github.com/gaosichun888/openprototype/blob/main/src/journey/journey.ts#L14-L22).

Frame Linking

A JourneyStage can optionally include a frameId [src/schema/types.ts:261-261](https://github.com/gaosichun888/openprototype/blob/main/src/schema/types.ts#L261-L261). This links the stage to a specific Frame on the canvas, allowing users to jump from the journey map directly to the corresponding UI design [src/views/JourneyView.tsx:187-187](https://github.com/gaosichun888/openprototype/blob/main/src/views/JourneyView.tsx#L187-L187).

Data Flow: Generation & Normalization

Journey maps can be generated via LLM providers or a local heuristic. Because AI outputs can be inconsistent, the system uses a "coerce" pattern to ensure data integrity.

Generation Heuristics

The generateJourneyFromBrief function (and its LLM counterparts) takes a text brief and returns a JourneyMap. If no API key is provided, the system falls back to a local generator that parses the brief for keywords to construct a logical sequence of stages [src/ai/generate.ts:218-223](https://github.com/gaosichun888/openprototype/blob/main/src/ai/generate.ts#L218-L223).

Normalization (Coerce)

The coerceJourney function ensures that any object (typically from an LLM) matches the expected schema. It validates that emotion scores are within the -2..2 range and that all required arrays (actions, pains, etc.) exist [src/journey/journey.ts:5-11](https://github.com/gaosichun888/openprototype/blob/main/src/journey/journey.ts#L5-L11).

JourneyView Matrix UI

The JourneyView component renders the map as a matrix where columns represent JourneyStage units and rows represent JourneyRow dimensions [src/views/JourneyView.tsx:174-216](https://github.com/gaosichun888/openprototype/blob/main/src/views/JourneyView.tsx#L174-L216).

EmotionCurve SVG

The "heart" of the journey map is the EmotionCurve component. It uses an SVG to render a continuous line representing user sentiment across stages. * Interpolation: It uses Catmull-Rom to Bézier conversion via emotionCurvePath to create a smooth, non-linear curve between discrete emotion points [src/journey/journey.ts:89-111](https://github.com/gaosichun888/openprototype/blob/main/src/journey/journey.ts#L89-L111). * Coordinate Mapping: The emotionPoints function maps the -2..2 score to the vertical y coordinate and the stage index to the horizontal x coordinate based on the container width [src/journey/journey.ts:114-131](https://github.com/gaosichun888/openprototype/blob/main/src/journey/journey.ts#L114-L131).

CellList Editing

Qualitative rows (e.g., Pains, Actions) are managed by the CellList component. It provides an inline-editing experience for arrays of strings, supporting "Enter to add" and "Click to remove" behaviors [src/views/JourneyView.tsx:25-76](https://github.com/gaosichun888/openprototype/blob/main/src/views/JourneyView.tsx#L25-L76).
