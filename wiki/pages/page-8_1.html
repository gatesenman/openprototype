Code Export (React, Vue, Tailwind, HTML, CSS)

The Code Export system is responsible for translating the internal GpoDocument canvas representation into production-ready code snippets and standalone prototypes. It employs a visitor-like pattern to traverse the node hierarchy and map design properties (positioning, styling, and content) to target-specific syntax.

Core Dispatcher & Registry

The system uses a centralized dispatcher to route export requests based on the requested language. This is primarily consumed by the Dev Mode panel for real-time inspection and the Export utilities for file downloads.

Styling Utilities

Styling is handled by a shared utility layer that converts Node properties into standard CSS-in-JS objects or string representations.

styleObject

The styleObject function src/export/exportCode.ts:4-35 is the source of truth for style translation. It maps: * Layout: x, y, width, height to absolute positioning src/export/exportCode.ts:7-12. * Appearance: radius to borderRadius, stroke to border, and shadow to boxShadow src/export/exportCode.ts:14-17. * Typography: text properties (color, size, weight, family) are mapped to flexbox containers to ensure vertical and horizontal alignment src/export/exportCode.ts:20-33.

toCssText vs toJsxStyle

  • toCssText: Converts a style object into a semicolon-delimited string (e.g., border-radius:8px;) src/export/exportCode.ts:37-44.
  • toJsxStyle: Converts a style object into a React-compatible object string (e.g., {{ borderRadius: 8 }}) src/export/exportCode.ts:46-51.

Framework Generators

React & Vue

Both React and Vue generators perform recursive tree traversal via nodeJsx src/export/exportCode.ts:53-62 and nodeVue src/export/exportCode.ts:138-145. * React: Generates a functional component using export default function Name. It uses inline styles for high fidelity to the canvas coordinates src/export/exportCode.ts:65-77. * Vue: Generates a Single File Component (SFC) with a <template> and <script setup> block. The root frame dimensions are defined as a reactive object in the script section src/export/exportCode.ts:148-166.

Tailwind CSS

The Tailwind generator src/export/exportCode.ts:172-205 uses arbitrary-value utilities (e.g., left-[10px]) to maintain the precision of the design canvas. * It iterates through the styleObject keys and pushes corresponding Tailwind classes into an array src/export/exportCode.ts:174-190. * Color tokens are resolved using nodeFill and wrapped in bg-[...] or text-[...] syntax src/export/exportCode.ts:175-184.

HTML/CSS (Class-based)

Unlike the inline-style generators, frameToCss creates a structured stylesheet src/export/exportCode.ts:119-123. * It generates unique class names based on the node name and index (e.g., .Hero-1) src/export/exportCode.ts:107-110. * It uses nodeCssRules to recursively build an accumulator of CSS blocks src/export/exportCode.ts:112-116.

Key Features of HTML Export:

  1. Interaction Wiring: The nodeHtml function searches for click triggers in node.interactions and injects an onclick handler calling gotoFrame src/export/exportHtml.ts:59-62.
  2. Runtime Script: A small JavaScript runtime is embedded in the exported HTML to handle frame transitions and animations (fade, slide-left, slide-right) src/export/exportHtml.ts:110-119.
  3. Device Simulation: The export wraps frames in a .device container with centered flexbox layout to simulate a mobile/web viewport src/export/exportHtml.ts:88-102.
  4. Download Utility: downloadHtml creates a Blob from the generated string and triggers a browser download using a temporary <a> element src/export/exportHtml.ts:124-133.
